# Overview

For this project, I am carrying out a Retail Sales Dataset analysis. For this exercise, I aim to answer two questions related to sales transactions. I am using Pandas as the tool to carry out this operation. My reason for choosing Pandas is because it is powerful, flexible, and compatible with python which would help strengthen my skills in the python ecosystem. And the overall purpose of this project is to help me kickstart my Data Analysis journey by helping me learn Pandas basics.

Below is the link of the data used in this project.

[Retail Sales Dataset](https://www.kaggle.com/datasets/danielsowah123/retail-sales-dataset)
